# Changelog

## 0.3.3 — 2026-10-28

- Refined neutral browser chrome, selected tabs, sidebar controls and settings navigation.
- Added HTTP/HTTPS links from other macOS applications and default-browser setup.
- Added Save Page (⌘S) and Print (⌘P).
- Added a verified drag-to-Applications DMG, checksums and public compatibility/privacy documentation.
- Added form, upload, page saving, PDF and external-link checks.
- Distribution remains a free non-notarized preview. iCloud passkeys, DRM and Chrome extensions remain unavailable.

## 0.3.2

- Faster selected-tab feedback and short reduced-motion-aware panel transitions.
- Await cookie writes before quitting; expanded storage/relogin tests.
- Added discoverable WebAuthn account selection. This does not enable iCloud passkeys.

## 0.3.1

- Fixed native Liquid Glass placement behind Chromium content.
- Preserved framework symlinks when publishing runnable app bundles.
